## 🚀 Featured Projects

### 📈 [TradeBrain](https://tradebrain.me): Stock Trading Terminal
Paper-trading platform for stocks, crypto and commodities, deployed on Azure.
- FastAPI order engine (market / limit / SL, 5× margin, auto square-off) on PostgreSQL with row-level locks
- Live feeds from **Upstox** (OAuth2, protobuf WebSocket) and **Binance**; loads 92k 1-min candles in ~4 s
- **Gemini** chat assistant with tool calling (quotes, zones, portfolio) and RAG over help guides
- Auto-detected demand/supply zones and a Nifty 50 zone + RSI screener
- Argon2 + JWT + email OTP auth, Razorpay (test mode), a 160-check Pytest suite, CI/CD with GitHub Actions

`FastAPI` `PostgreSQL` `WebSockets` `Gemini` `React` `Azure`

### 🕵️ [Face Search Engine for Criminal Identification](https://github.com/Sagarkumar3836/REPO_NAME)
FastAPI backend built for the **CG Police Dept.** (supervised by NIT Raipur faculty).
- ArcFace embeddings + **FAISS** similarity search over a MySQL image database
- `/search` API: upload a photo and get the closest matches with distances

`FastAPI` `InsightFace` `FAISS` `MySQL`

### 📊 AI-Assisted Swing Trading System (Research)
- Rule-based detection of RBR / DBR / DBD / RBD zones with swing highs/lows and candle-strength filters
- Multi-timeframe feature pipeline (pin bars, engulfing, doji) + **XGBoost** with walk-forward validation
- Backtesting engine tracking win rate, Sharpe ratio and max drawdown, with no look-ahead bias

`Python` `XGBoost` `Pandas` `NumPy`
